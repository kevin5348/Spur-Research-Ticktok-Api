TikTok Research API Pipeline

A Python data pipeline developed during a Maynooth University SPUR research internship. It uses the TikTok Research API to collect and prepare video and comment data for research into company controversies and responses.

Features
Searches for videos using company keywords and hashtags
Splits searches into valid 30-day date ranges
Handles pagination, duplicate videos and API rate limits
Collects video metadata and comments
Saves progress during long-running collections
Exports and filters the collected data for analysis
